# Telegram Mini-Bank Bot

**Описание:**  
Это Telegram-бот с внутренней банковской системой и системой бонусных баллов. Идеален для мотивации команды, геймификации или учебных проектов. Боты не работают с реальными деньгами — все переводы и баллы условные.

---

## Основные возможности

### Банковская система
- Создание и управление личными счетами.
- Переводы между собственными счетами по имени.
- Переводы на чужие счета только по номеру счета.
- История транзакций и проверка баланса.

### Система бонусов
- Начисление баллов за события (например, подтверждённые заказы).
- Просмотр текущего баланса и истории начислений.
- Лидерборд пользователей по баллам.
- Возможность обмена баллов на нематериальные вознаграждения.

### Админ-панель
- Проверка всех транзакций.
- Подтверждение крупных начислений.
- Управление правилами начисления и списания баллов.
